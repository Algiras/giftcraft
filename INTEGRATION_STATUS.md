# Integration status (2026-09-10)

Local tests: 17 passed; TypeScript and production build passed. Gift option configuration persists through private Wix Data storage; the dashboard contains a calculation/message preview. A registered Additional Fees service plugin reads the same configuration and returns line-item-associated wrap/card fees only when a shopper selected a matching native Wix Stores product modifier (`GiftCraft wrap`, option label matching the configured name; optional `GiftCraft greeting card` value `Yes`). Wix includes additional fees on the resulting order.

The native product modifier provides the current shopper-selection and order-line-item persistence path. There is no app-owned checkout selector, greeting-message order attachment, fulfillment handoff, or free-gift order insertion. Do not charge fees based only on merchant options: a validated shopper selection must first be bound to the checkout and carried into the order. Billing entitlements and installed-site save/reload/checkout/order acceptance remain unverified. Dashboard copy states the required modifier setup and does not claim an attach-rate outcome. No deployment or browser interaction occurred.
